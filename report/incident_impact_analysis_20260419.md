### 結果取得失敗の原因 (推定)
- 22:00 時点でも netkeiba が結果テーブルを公開していない、または race_id 形式と URL の不一致
- fetch_race_result() の URL: `https://race.netkeiba.com/race/result.html?race_id={race_id}`
- race_id が `202606030801` 等 (期待形式 `2026XXXXXXXX`) — 2026年のため未確定の可能性あり
- → 本フェーズでは結果ベースの IF-ROI 計算不可。**歴代実績 ROI での期待損失算出に切替**

## 4. 機会損失

### ★ 午前 R1-R6 スキップによる推定機会損失: **約 +2,745円**

- 投資予定額 11,900円が未発注で済んだが、期待プロフィット +2,745円を逃した
- 条件別の損失:
  - A (5R) 期待 +802円
  - C (6R) 期待 +1,000円
  - D (5R) 期待 +1,551円 ← 最大
  - E (1R) 期待 -608円 (これは回避できて正解)

### 午前中スキップの「得」
- 条件 E の 1R (期待 ROI 13.2%) は発注しなくて済んだ → 608円 節約

### ネット損失
- +2,745円 - (-608円 節約分は既に計算に入っている) = **約 +2,745円 を逃した**
- 投資比損失率: 2,745 / 11,900 = **23.1%**
