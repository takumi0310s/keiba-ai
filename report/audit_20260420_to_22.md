## 4. ★ 検出した問題: AM3FireCheck 3日連続 CRITICAL 誤通知

### 症状
平日の DailyPremiumScrape ログ (339B、正常早期終了) を AM3FireCheck が
「ログサイズ異常 339B (最低2000B期待)」として CRITICAL 判定し、Discord に
不要な緊急通知を3日連続で送信。

### 根本原因
`tools/am3_fire_check.py` のサイズ判定が、ログ本文を見ずに `size < 2000` で
即 CRITICAL を返していた。「No races found」の正常終了パターンを未識別。

### 修正
- `tools/am3_fire_check.py`: size < 2000 でも `"No races found"` を含めば OK 判定
- `tools/fire_check_common.py`: 同じく size < min_size でも `"No races found"` で OK 判定
  (AM6/AM8 でも同種のリスクがあるため defensive)

### 検証
4/22 のログ (339B) で再実行 → status="ok" "平日 (非開催日) のため正常早期終了" を返した。
