| 段階 | AUC | 差の要因 |

| Grid 4-model・旧(リーク)キャッシュ | 0.8858 | — |
| **2-model (LGB+XGB)**・同キャッシュ | ~0.869 | −0.017 = FT+IR の寄与。★productionのinferenceは2-modelのみ (V15-audit-1) → 0.8858はそもそも本番構成の数値ではない★ (master_report yearly の lgbxgb_auc 0.8665-0.8718 が一次ソース) |
| 2-model・**leak-free v2** キャッシュ | 0.842〜0.8407 | −0.027 = ze-leak (全期間平均が結果混入)+S1 の除去 (6/2-4 監査、CLAUDE.md「leak-free v2 WF ~0.842」と本検証(d)0.8407 が整合。0.842は2023-25fold/0.8407は2021-25foldの期間差) |

★**9月判定の正 = (e) 0.8154 系 (真値 0.812-0.815)**。0.8858 は「非本番構成 (4-model) × リーク入りキャッシュ」の歴史値であり、本番推論の指標として使わない。★
