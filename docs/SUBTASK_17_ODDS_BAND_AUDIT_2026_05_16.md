## 9. 戦略⑦案 C 拡張候補

### 候補 ★1: **odds [5.0-20.0) fence** (= 「odds < 5 または odds >= 20 を 除外」)
- pre-5/16 (4/18-5/10): **戦略⑦ + odds [5.0-20)** = **N=43 ROI 122.6% +6,790円**
- full window (4/18-5/16): **N=65 ROI 134.6% +15,730円**
- **論拠**:
  - 1.5-5.0 band は p<0.05 で under-perform (信頼区間 上限 < 100%)
  - 20.0+ band は p<0.001 で under-perform (大穴 ratio が hit-rate を 超える)
  - 5.0-20.0 は jackpot 期待値 を 取り込む sweet spot
- **risk**: CI 広い、 paper eval 1-2 か月 必須

### 候補 ★2: **20.0+ 除外 のみ** (シンプル)
- pre-5/16: 20.0+ ROI 34.3% N=34 (p=0.0008)、 損失 -15,630円
- 戦略⑦ + odds<20: **N=92 (戦略⑦ base から 20.0+ 抜く) ROI 推定** (再計算 below)

### 候補 ★3: **東京の 5.0-10.0 除外**
- 東京 5.0-10.0 = N=14 / 0 hit / ROI 0% / -9,800円
- これ単独で 大きな loss source、 場×band 限定なら N が小さい paper 必要

### 候補 ★4 (PASS、 N不足): **過剰人気 odds<1.5 除外**
- N=1 で 判定 不能、 6月+ 様子見

### 戦略⑦案 C 統合提案 (5/18+ paper eval 対象)

```python
# tools/race_auto_notify.py predict_and_notify() 内に追加
def apply_odds_band_filter(top1_odds: float) -> bool:
    """Return True if bet should be PLACED (passes filter)."""
    if pd.isna(top1_odds):
        return True  # odds 未取得 → 既存通り bet
    if top1_odds < 5.0:
        return False  # 1.5-5.0 band は under-perform (p<0.05)
    if top1_odds >= 20.0:
        return False  # 20.0+ は under-perform (p<0.001)
    return True
```

**期待効果** (pre-5/16 sample):
- 戦略⑦ N=92 → 戦略⑦ + odds[5,20) N=43 (-49 races / 53% 削減)
- ROI 84.7% → 122.6% (+37.9pt)
- profit -9,840円 → +6,790円 (+16,630円改善)

**注意**:
- N=43 / 4-5月 のみ、 信頼区間 [-20pt, +60pt] 程度
- 蓄積 N≥100 で 再評価 推奨 (7月+)
- 5/16 jackpot を 入れた full window では ROI 134.6% / N=65 (より sample 大)
