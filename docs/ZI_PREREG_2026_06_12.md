## Phase 1 裏取り結果 (一次ソース)

### ZI指数の正体 (TARGET公式FAQ id=593 / target.a.la9.jp)
- 計算要素: **前走の着順・人気・着差・連対率・頭数の増減・斤量の増減・脚質** を数値化
- **走破タイムは一切不使用**・**今走のオッズ/人気は不使用**
- → **PRE-RACE性 = 安全** (前走確定時点=前日に算出可能。確定後情報を含まない)
- ★ただし公式の用途説明が「前日予想時の人気の判断」「今走の人気とほぼ比例」 = **設計目的が人気代理** → kill基準(a) に直結するリスクを事前に明記★
- ★V15 既存特徴との重複 prior: 計算材料 (prev_finish/着差/斤量変化/頭数/脚質) は V15 の前走族とほぼ同一。
  ZI の増分仮説 = 「手作りの合成方法そのものに情報がある」のみ → **prior は低**と正直に記録★

## Phase 2 — kill 基準 (事前登録・変更禁止)

検証 = leak-free v2 cache (2023-25 WF、V15 145特徴ベース)。

- **(a) 市場代理チェック**: ZI (生値) と前日人気 (oz_base_pop_rank) のレース内 Spearman 相関の平均 > **0.85** → 「市場代理」として打ち切り。s2b には入れない・V15 にも増分期待なしと記録
- **(b) 増分チェック**: V15 全145特徴 + ZI変種 の WF AUC 増分 < **+0.002** → 打ち切り (NO-GO台帳へ「市販指数カテゴリ」として記録)
- **(c) 変種は m=3 で固定 (途中追加禁止)**:
  1. ZI 生値
  2. ZI レース内 z-score
  3. ZI レース内順位
