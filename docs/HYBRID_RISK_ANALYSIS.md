# hybrid 戦略 risk 分析 (Session #82)

## 1. 投資金額増加 risk

### 1.1 投資額 試算

| 項目 | 7 点 strict (現状) | hybrid (cell 1 = 11 点) | 増加 |
|------|------------------|------------------------|------|
| 1 R 投資 | ¥2,100 | cell 1: ¥3,300 / 残り: ¥2,100 | +57% (cell 1) |
| 月 50 R 想定 | ¥105,000 | cell 1 25 R + 他 25 R = ¥135,000 | +28% |
| 半年 | ¥630,000 | ¥810,000 | +28% |

### 1.2 撤退余裕への影響

| シナリオ | 月 P/L | 半年 P/L | 撤退余裕への影響 |
|----------|--------|---------|-----------------|
| hybrid 期待通り (ROI 132%) | +¥4,500 | +¥27,000 | 撤退余裕 拡大 |
| hybrid 期待外 (ROI 100%) | ±0 | ±0 | 撤退余裕 維持 |
| hybrid 失敗 (ROI 80%) | -¥6,000 | -¥36,000 | 撤退余裕 縮小 ★ |

**最悪シナリオ**: hybrid ROI 80% で半年 -¥36,000
→ 撤退余裕 +¥64,000 (現在) - ¥36,000 = +¥28,000 (依然黒字)
→ ★許容範囲内★

### 1.3 mitigation
- 上限 1 万円/日 strict 維持
- 月次 ROI 監視、 < 100% で 即時 paper に戻す

## 3. over-fitting risk

### 3.1 risk 内容
Session #69 の発見:
- 芝 11 点: +18.1pt
- ダート 11 点: -11.2pt

→ サンプル分割で生まれた spurious effect の可能性。

### 3.2 検証 method
- bootstrap CI95 で確認
- cell 1 lower bound > 0pt 確認
- P 値 < 0.05 検証

### 3.3 mitigation
- bootstrap 必須
- 各 cell ≥ 100 R 厳守
- temporal validation (前半 / 後半 で同じ結論か確認)

## 4. V18/V20 model 変更との衝突 risk

### 4.1 V18 trial (5/16)
- V18 trial = 1 day のみ、 hybrid 評価に影響微小
- V18 case でも 7 点 strict 維持 → hybrid と直交

### 4.2 V20 投入 (7/1)
- V20 + hybrid 同時投入は効果切り分け不能 ★
- → V20 単独 1 ヶ月 → 8/1 hybrid 判定 (Session #82 D 確定)

### 4.3 mitigation
- V20 投入後 1 ヶ月は hybrid 投入禁止
- 8/1 判定時、 V20 単独 ROI baseline 確定済み

## 8. 結論

| risk | severity | mitigation 妥当性 |
|------|---------|-----------------|
| 投資金額増加 | low | 上限額 strict 維持で許容範囲 |
| サンプル不足 | medium | 8/1 までに 200 R 達成見込 |
| over-fitting | medium | bootstrap で検証 |
| V18/V20 衝突 | low | V20 単独 1 ヶ月で切り分け |
| 戦略⑦衝突 | low | 直交、 同時運用可能 |

→ ★全 risk は mitigation 可能、 採用候補★ 8/1 判定 GO 候補。
