| `training_time_filled` | 7.0 | 中位 | 5.36% | 調教タイム (標準) |

### ninki_idx を除外した場合の uma6 推定順位

- ninki_idx (z=+0.10) の寄与は中立的 — 高くも低くもない
- `jrdb_ze_idm_avg=39.7` (全馬最高) の寄与は ninki 除外後も残存
- → ninki_idx 除外後、uma6 は **#1〜#3 の範囲を維持** と推定 (uma2 が歴史 SED 弱ければ #1 堅持)

### オオタニサーン — 根拠の質

```
能力系根拠 (強):
  ✓ jrdb_ze_idm_avg = 39.7 — 15頭中 全馬最高 (gain 9.4%)
  ✓ horse_career_wr = 16.7% — 上位 (gain ~5%)
  △ paci_jockey_exp_wr = 20.9 — 中位 (gain 16.3%)

人気系根拠 (弱):
  △ paci_ninki_idx = 138 (z=+0.10) — 中立的。貢献は小さい
```

**→ オオタニサーン の1位は「歴史スピード指数 + 戦績勝率」が主軸。人気は追随因子。**


## 7. ★ honest verdict ★

### オオタニサーンは「人気以外の根拠」で選ばれているか?

**→ YES。能力系根拠が主軸。**

- `jrdb_ze_idm_avg=39.7` (全馬最高) + `horse_career_wr=16.7%` は人気とは無関係な実績指標
- `paci_ninki_idx=138` (z=+0.10) は中立的な寄与 — なくても top3 を維持できる強度
- 「PACI 能力順位が7位でも V15 で#1」の理由: PACI は今日の予測値、V15 はレース履歴の蓄積 (SED IDM 平均) を重視するから

> **オオタニサーン = "能力で選ばれた"** が正確。人気は追随因子に過ぎない。

---

### ペッパーミルは「人気だけ」か?

**→ ほぼそう (ninki_idx 主導)。複数根拠はあるが弱い。**

- ninki_idx を除外すると能力系指標のみでは #4-7 圏
- `paci_stable_idx=8.3` (厩舎コンディション良好) は補助根拠として有効
- しかし `horse_career_wr=5.6%` の低さが能力系での評価を大きく引き下げている
- 「18走1勝でも2位」の理由は明確: **JRDB の事前人気評価が高いから**

> **ペッパーミル = "人気 (ninki_idx) が2位の主因"** が正確。能力系は不十分。

---

### V15 は馬により「根拠の質」が違うか?

**→ YES。同じ V15 スコアでも根拠の源泉は異なる。**

| 馬 | スコア源泉 | ユーザーへの含意 |
|----|---------|--------------|
| オオタニサーン | 能力系 (SED 歴史実績 + 戦績) | 信頼度高い — 実力ベースの選択 |
| ペッパーミル | 人気系 (ninki_idx = JRDB 事前評価) | 注意が必要 — 人気裏切り時にリスク |
