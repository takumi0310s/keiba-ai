| 指標 | V15 実績 | JRA 1番人気 (公開統計) | ランダム (14頭平均) |
|------|----------|----------------------|-------------------|
| TOP1 1着率 | **24.5%** | ~33% | ~7% |

| TOP1 複勝率 | **55.2%** | ~65% | ~21% |
| 三連複 7点的中率 | **22.3%** | N/A | ~4.1% (注3) |

**注3**: ランダム 7点の的中率推定 = 7 / C(n,3) の平均 (買い目内の最大馬番をサンプルに使用して試算)。

### 解釈

- V15 は**ランダム比で TOP1 複勝率 2.6倍** (55.2% vs 21%)。
- JRA 1番人気比では **連対率 -7pt / 複勝率 -10pt** 下回る。ただし人気は当日オッズ情報を含む (Pattern B 特徴量 `odds_log` / `pop_rank`)。Pattern A (リークフリー) 評価では差は縮まる可能性がある。
- 三連複 7点的中率 22.3% はランダムの **約 5.4倍**。

## 8. データ制限事項

1. **top1_score 78.4% 欠損**: V15 の予測スコアそのものが大半の期間で不揮発化されていなかった。信頼区間計算やスコア×精度の相関分析は現状困難。
2. **num_horses 98.9% 欠損**: ランダムベースラインの精密計算 (頭数別) が不可能。本レポートではサンプルベースの概算を使用。
3. **trio_bets (朝予測) 96.9% 欠損**: 朝と夕方 (race_time) の予測精度差の比較が不可能。
4. **人気情報なし**: 1番人気馬の馬番が `cumulative_results.csv` に記録されていないため、V15 と人気の直接的中比較は不可能 (公開統計値との比較のみ)。
5. **race_notify_log_v2 の phase3 (結果)**: 2026-05-17 以降の phase3 ログはほぼ空 (結果登録が未実施)。`cumulative_results.csv` の `top1_finish` が信頼できるメインソース。

## 9. 今後の精度追跡のための提言

### 即実施可能

1. **`top1_score` の常時記録化**: `race_auto_notify.py` の phase1 ログは既に `ranking_top5[].score` を記録している。`cumulative_results.csv` への書き込みを `top1_score` カラムに自動追記する処理を追加する。

2. **`num_horses` の常時記録化**: phase1 ログの `race_meta.num_horses` から取得可能。`cumulative_results.csv` 書き込み時に填埋する。

3. **人気情報の記録**: `morning_odds` (phase1 ログに記録済み) からソートして 1番人気馬番を `pop1_umaban` として記録し、V15 TOP1 との一致率を追跡する。

### 中期的

4. **日次精度モニタリング**: `tools/daily_results.py` に精度サマリ (TOP1 複勝率・三連複的中率) の計算と Discord 通知を追加。週次集計で季節性・条件別の精度変動を追う。

5. **条件別サンプル増加**: 条件 B (N=16) / 条件 E (N=11) / 条件 X (N=18) は N が少なく CI が広い。1開催 10-20 件のペースで蓄積するには B=3ヶ月、E=X=3ヶ月以上が必要。

6. **スコア閾値フィルタの検証**: `top1_score` の高い (例: 上位 30%) レースに絞った場合の精度を追跡し、EV フィルタの有効性を実データで確認する。

## 付録: 集計スクリプト再現手順

```python
import pandas as pd

df = pd.read_csv('data/cumulative_results.csv')
settled = df[df['status'] == 'settled'].copy()
settled['top1_finish_f'] = pd.to_numeric(settled['top1_finish'], errors='coerce')
settled['top2_finish_f'] = pd.to_numeric(settled['top2_finish'], errors='coerce')
settled['top3_finish_f'] = pd.to_numeric(settled['top3_finish'], errors='coerce')
valid = settled.dropna(subset=['top1_finish_f', 'top2_finish_f', 'top3_finish_f'])

print(f"TOP1 複勝率: {(valid['top1_finish_f'] <= 3).mean()*100:.1f}%")
print(f"三連複 7点的中率: {valid['trio_hit'].mean()*100:.1f}%")
```
