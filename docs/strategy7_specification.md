## 🎯 適用条件 (4種)

### 1. 06_特別の除外
**対象**: G1/G2/G3/L/OPの特別レースではない、平場の特別

```python
is_graded = any(g in race_name for g in ['G1', 'G2', 'G3'])
is_listed = any(s in race_name for s in ['L)', '(L)', 'OP)', '(OP)'])
is_open_tokubetsu = any(s in race_name for s in ['杯', '賞', 'ステークス', 'カップ', 'ハンデ'])

if '特別' in race_name and not (is_graded or is_listed or is_open_tokubetsu):
    return  # Skip
```

**実証データ**: -9,470円損失源 (4/12-4/26 直近4週)

### 2. 京都の除外
**対象**: 京都競馬場の全レース

```python
if course == '京都':
    return  # Skip
```

**理由**: 2023年4月リオープン後のデータ蓄積待ち
**解除予定**: 5/11以降 (京都の戦略⑦適用後ROI評価)

### 3. 条件E の除外
**対象**: 頭数 <= 7 のレース

```python
if cond_key == 'E':
    return  # Skip
```

**理由**: サンプル数少 + ROI不安定

### 4. 条件B の除外
**対象**: 馬場状態が重 〜 不良

```python
if cond_key == 'B':
    return  # Skip
```

**理由**: 馬場特殊条件で予測精度が落ちる
