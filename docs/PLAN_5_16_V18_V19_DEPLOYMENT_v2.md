## 3. Kelly fraction 計算 (V18 sib_exp 単独想定)

### 3.1 BT 数値

| 指標 | V18 sib_exp |
|------|-----------|
| BT WF AUC | 0.8845 |
| BT winner_top1 | 45.88% (Session #41 D) |
| LIVE winner_top1 | 31.03% (1 週分、 推定) |
| 平均 単勝 odds (top1 馬) | ~5-8 倍 (推定) |

### 3.2 Kelly fraction

```
p = LIVE winner_top1 = 0.31
b = (平均 odds 6 - 1) = 5
q = 1 - 0.31 = 0.69

f* = (b*p - q) / b
   = (5*0.31 - 0.69) / 5
   = (1.55 - 0.69) / 5
   = 0.172  (= 17.2%)
```

→ Full Kelly 17.2%、 Quarter Kelly **4.3%**、 Eighth Kelly 2.2%

### 3.3 推奨 Eighth Kelly (2.2%) で 慎重投資

```
資産 +13,530 円 × 2.2% = 約 297 円 / race
→ 500 円 / race は Eighth Kelly よりやや積極的、 撤退余裕 +63,530 円考慮なら許容
```
