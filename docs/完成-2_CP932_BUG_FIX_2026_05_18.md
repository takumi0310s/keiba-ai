## 1. bug root cause

### 症状
5/18 B-5 dry-run で `tools/daily_cumulative_audit.py` 実行時、 cp932 env で
`UnicodeEncodeError: 'cp932' codec can't encode character '✅' in position 228`
で crash (exit code 0 で 偽の成功表示、 実 trace は cp932 console に出力不能)。

### 真因
1. `daily_cumulative_audit.py` の `detect_drift_claude_md()` が
   `CLAUDE.md` を utf-8 で 読み込み、 旧値残存 line を そのまま stdout に print
2. CLAUDE.md L19 には `✅` (`✅`) emoji が混入
3. schtask が stdout/stderr を log file に redirect 時、 default は
   cp932 (Windows console codepage) → encode 不能 → crash
4. Python 3.7+ では `sys.stdout.reconfigure(encoding='utf-8')` で 解決可能
5. 既存 `tools/anomaly_auto_detector.py` L41-46 では 既に対応済、 他 4 file は 未対応

### 再現 (cp932 simulation)
```
PYTHONIOENCODING=cp932 python tools/daily_cumulative_audit.py --no-discord
→ UnicodeEncodeError: 'cp932' codec can't encode character '✅' (= ✅)
```

### 共通 fix pattern (新規 4 file)
```python
# Windows cp932 console で 絵文字 / yen sign 印字 → utf-8 化 (schtask redirect 対策)
if sys.platform == 'win32':
    try:
        sys.stdout.reconfigure(encoding='utf-8', errors='replace')
        sys.stderr.reconfigure(encoding='utf-8', errors='replace')
    except Exception:
        pass
```

- 関数 signature / return value / 計算 logic 完全不変
