- SED IDM 全平均: **39.7**
- SED IDM 直近5走平均: **38.4**

### 選定理由サマリー

**主因①**: `jrdb_ze_idm_avg` = 39.7 — V15の4番手特徴量(gain 9.4%)でレース内最高値。  
→ 直近6走のスピード指数平均がこのメンバーで最も高い。

**主因②**: `paci_sogo_mark` = 7.0 (z=+1.39) — 総合評価でレース内断トツ1位。  
→ JRDB がこの馬の総合力を最高評価。

**主因③**: `paci_jockey_exp_wr` 20.9% (z=+0.51) / `paci_jockey_exp_3rd` 32.1% (z=+0.58) — V15の2〜3番手特徴量(合計31.1% gain)で平均以上。

**主因④**: `horse_career_wr` 16.7% (6走1勝) — ペッパーミル(5.6%)より3倍高い。

**朝人気寄与**: 2番人気(5.6倍) → `pop_rank_change` / `oz_base_pop_rank` 経由で微小に寄与 (合計 ~0.97% gain)。  
→ 朝2番人気は「高スコアだから人気」でも「人気だからスコア」でもなく、**双方向の一致**。

## 3. ペッパーミル (馬番10) — 2位選定理由 (18走1勝)

### 戦績
- キャリア: 18走1勝 (勝率 **5.6%**)
- SED IDM 全平均: **36.4** (オオタニサーンより -3.3)
- SED IDM 直近5走平均: **38.4** (直近は復調)
- 直近走: IDM 26(R13, 大不振) → 46(R5) → 45(R4) → ...

### PACI 特徴量 z-score (レース内15頭)

| feature | V15 gain% | 実値 | z-score | 評価 |
|---------|----------|------|---------|------|
| `paci_ninki_idx` | **16.9%** | **180** | **+0.58** ← 主因 | ◎ |
| `paci_jockey_exp_wr` | **16.3%** | 20.9% | +0.51 | 上 (同騎手) |
| `paci_jockey_exp_3rd` | **14.8%** | 32.4% | +0.60 | 上 (同騎手) |
| `jrdb_ze_idm_avg` | **9.4%** | 36.4 | < オオタニ | 下位 |
| `paci_stable_idx` | — | +8.3 | **+0.89** | ◎ 厩舎評価 |
| `kyakushitsu` | — | 1 (逃げ) | **-1.36** | 不利 |
| `horse_career_wr` | 1.2% | 5.6% | ← 18走1勝 | 低い |

### なぜ 18走1勝で 2位か

**V15 は raw 勝率を直接使わない。JRDB 総合指数が主役。**

1. **`paci_ninki_idx` = 180 (z=+0.58)** — V15 最重要 feature (gain 16.9%) で上位。  
   → JRDB が「このメンバーでは相対的に強い」と評価している。18走1勝の raw 戦績より重い。

2. **`paci_stable_idx` = +8.3 (z=+0.89)** — 厩舎の直前評価が高い。  
   → JRDB タイム予想は直前情報を加味 → 状態良化サインを捕捉。

3. **騎手特徴量**: ペッパーミルはオオタニサーンと同騎手 → `paci_jockey_exp_wr` / `3rd` 同値。  
   → 騎手分は両馬で差がつかない (プラスマイナスゼロ)。

4. **直近復調**: 直近2走 IDM 46/45 — 前走不振(IDM 26)から回復の兆候。  
   → `jrdb_ze_idm_avg` に直近重みがあれば部分的に反映。

### ペッパーミルが 1位でなく 2位に留まった決定的 feature

| 要因 | オオタニ | ペッパー | 差の方向 |
|------|---------|---------|---------|
| `jrdb_ze_idm_avg` (9.4%) | **39.7** | 36.4 | -3.3 → オオタニ有利 |
| `paci_ninki_idx` (16.9%) | 138 | **180** | ペッパー有利 |
| `paci_sogo_mark` | **7.0 (z=+1.39)** | 6.0 (z=+0.93) | オオタニ有利 |
| `horse_career_wr` (1.2%) | **16.7%** | 5.6% | オオタニ有利 |
| `kyakushitsu` | 3(差し) | **1(逃げ, z=-1.36)** | 逃げ不利 |

**結論**: `paci_ninki_idx`(180) でペッパーミルは追いつくが、`jrdb_ze_idm_avg`(-3.3差)と `paci_sogo_mark`(-0.46σ)と `horse_career_wr`(3倍差)の複合で逆転できず 2位。

## 4. 2頭の比較 — 人気寄与 vs 戦績以外の寄与

### 直接オッズ系 (V15 gain 合計 ~1.2%)

| feature | gain% | 両馬への影響 |
|---------|-------|------------|
| `pop_rank_change` | 0.83% | 朝2番人気(オオタニ) / 3番人気(ペッパー) → 微差 |
| `oz_base_pop_rank` | 0.14% | 同上 |
| `odds_change_rate` | 0.12% | 両馬とも当日下落 → ネガティブ方向 |
| **合計** | **1.09%** | — |

→ **直接オッズ寄与は 1.09% のみ。スコア差 0.0126 の大半は oッズ以外から来ている。**

### 実質的な差分を生んだ feature

| feature | 寄与 (推定) | 勝者 |
|---------|-----------|------|
| `jrdb_ze_idm_avg` (9.4%) | 最大差 | オオタニ (+3.3pt = 約 +0.003〜+0.005 スコア) |
| `paci_sogo_mark` | 2番目差 | オオタニ (+0.46σ) |
| `paci_ninki_idx` (16.9%) | 3番目差 | ペッパー (+0.35σ) |
| `horse_career_wr` (1.2%) | 小差 | オオタニ (16.7 vs 5.6%) |
| `kyakushitsu` (逃げ罰則) | 小差 | オオタニ (差し優位) |

### 結論

**オオタニサーン 1位の主因**: スピード指数 (`jrdb_ze_idm_avg` 39.7) と JRDB 総合評価 (`paci_sogo_mark` +1.39σ) が全馬最高水準。朝2番人気は追い風だが、主因ではない。

**ペッパーミル 2位の主因**: 18走1勝の raw 戦績ではなく `paci_ninki_idx` = 180 (+0.58σ, V15最重要 feature) が支えている。V15 は「JRDB がこのメンバーで上位評価しているか」を見る。厩舎評価 (`stable_idx` +0.89σ) も後押し。

**スコア差の内訳 (推定)**:
- 人気/オッズ系: **~0.001** (1.09% gain が tiny gap → 微差)
- スピード指数系 (`jrdb_ze_idm_avg` 他): **~0.005〜0.007**
- JRDB 総合系 (`sogo_mark` 他): **~0.003〜0.005**
- 残差 (訓練依存): ~0.003

→ スコア差 0.0126 の **約 90% は戦績・スピード指数・JRDB評価** から。**オッズ寄与は ~10%** 以下。
