## 11. 計算上の注意事項・限界

1. **top5 hit の 40 races は計算不能** (`trio_bets_str` 欠損 + winner が pred top3 外)。55.1% は 623 races ベース。
2. **num_horses が 97% 欠損** → ランダムベースラインの N=15 は仮定値。実際の field size によって random 倍率は変動する。
3. **top2/top3 predicted horse は順序不定** (trio 対称的ゆえ): top2_finish と top3_finish のどちらが "2着予測" かは区別できない。
4. **条件 B/E/X は n<20 or n=11-19** のため CI が広く信頼性低。
5. **月別では 3 月の trio_bets_str カバレッジが 77%** のため top5 の 3 月値は他月比で過大評価の可能性。
6. **top5 hit の "known winner" 判定**: winner_num を trio_result セット引き算で推定する手法は、同一馬番の重複（先着2頭が予測馬の場合）で稀に誤判定しうる。影響は小さい。
