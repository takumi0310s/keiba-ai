## 12. 方法論 + fabrication 防止

- input: `data/cumulative_results.csv` (V15 LIVE prediction settled rows) + `data/jra_payouts.csv` (JRA 公式配当)
- top1/top2/top3 抽出: `trio_bets_str` の 7 点 fomation から 全行に共通する horse = TOP1、 残り 出現頻度 順 で TOP2/TOP3
- 配当 lookup: `(race_date, course, race_num)` で inner join
- 5 大券種 (単勝 / 馬連 / ワイド / 三連複 / 三連単) を T1 / T1-T2 / box3 / formation 等 複数 方式 で 計算 (計 11 投資 pattern)
- ROI = 払戻合計 / 投資合計
- 95%CI: bootstrap 1000 iter (per cell, seeded by hash)
- 統計検定: 1-sample Welch t-test (per-race return ratio vs 0)
- 並列計算: multiprocessing.Pool (n_workers=8)
- N<30 cell は **sample 不足** を必ず明示、 採用見送り
- "想定" の数値 0 件 — 全数値 cumulative_results.csv + jra_payouts.csv の 実測値
