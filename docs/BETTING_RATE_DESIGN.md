# 馬券内率設計 — 能力・オッズ・妙味の分離

**作成**: 2026-05-24  
**変更**: 表示情報の追加のみ。V15/V16 予測 logic 完全不変。

---

## 1. 設計思想

> **オッズは結果。馬券内率は能力のみで算出し、オッズとは別表示。乖離を妙味判定とする。**

| 列 | 算出根拠 | オッズ混入 |
|----|---------|-----------|
| V15スコア | V15 モデル (paci_ninki_idx 込み) | あり (意図的) |
| 能力馬券内率 | V16スコア → キャリブレーション変換 | **ゼロ** |
| 単勝オッズ | 市場オッズ | — (参考表示) |
| 妙味判定 | 能力馬券内率 vs オッズの乖離 | 表示のみ・投票判断外 |

---

## 2. キャリブレーション (V16 スコア → 馬券内率)

**ファイル**: `data/v16_calibration.json`  
**手法**: WF fold (train 2020-2024 / test 2025 OOS) の予測スコアと実際の 3着内 (finish ≤ 3) を 0.05 幅バケツで集計。

| スコア | N | 馬券内率 |
|--------|---|---------|
| 0.00–0.05 | 16,833 | 1.8% |
| 0.10–0.15 | 4,382 | 14.3% |
| 0.20–0.25 | 2,673 | 26.2% |
| 0.30–0.35 | 1,879 | 38.7% |
| 0.40–0.45 | 1,333 | 46.3% |
| 0.50–0.55 | 1,015 | 56.8% |
| 0.60–0.65 | 800 | 69.6% |
| 0.70–0.75 | 658 | 80.5% |
| 0.80–0.85 | 420 | 86.0% |

> スコアが単調増加で馬券内率も単調増加 → キャリブレーション健全。

---

## 3. 妙味判定ロジック (`_myomi_label()`)

| 条件 | ラベル | 意味 |
|------|-------|------|
| 能力≥40% かつ オッズ≥7.0 | `★穴` | 能力高い・人気薄 = 妙味あり |
| 能力≥40% かつ オッズ<7.0 | `〇順` | 能力高い・人気も高い = 順当 |
| 能力<25% かつ オッズ≤4.0 | `△危` | 能力低い・人気過大 = 危険 |
| その他 | (空白) | 中立 |

**重要**: 妙味判定はあくまで表示補助。投票判断は V15 スコア順フォーメーションのみ。

## 4. 通知フォーマット (能力馬券内率 + オッズ + 妙味)

```

▶  1番  6 オオタニサーン 0.49 能:46% O7.0 ★穴
▶  2番 10 ペッパーミル  0.48 能:26% O3.5 △危
▶  3番 11 ホワイトイニコ… 0.34 能:38% O4.2
──────────────────────────
   4番 15 アメリカンウィ… 0.25 能:20% O12.0
   ...
★能=V16キャリブ馬券内率(能力のみ)・オッズ参考・投票はV15
```

**フォールバック**:
- odds_dict なし → V16 スコア + 人気 (妙味判定なし)
- v16_scores なし → V15 スコア + 人気 + 過去複勝率

## 5. 実装

| 関数 | ファイル | 役割 |
|------|---------|------|
| `_load_v16_calib()` | `tools/notify.py` | JSON 読み込み (1回のみ) |
| `_score_to_top3r(score, buckets)` | `tools/notify.py` | スコア → 馬券内率ルックアップ |
| `_myomi_label(calib_prob, odds)` | `tools/notify.py` | ★穴/〇順/△危 判定 |
| `_build_all_scores_table(df, v16_scores, odds_dict)` | `tools/notify.py` | Discord テーブル構築 |
| `build_rich_bet_message(..., odds_dict=odds_dict)` | `tools/notify.py` | テーブルに odds_dict を転送 |

---

## 6. 制約

- **★ 馬券内率にオッズを混ぜない ★**: `_score_to_top3r` は V16 スコアのみを入力、オッズは使用しない
- V16 は paper 検証前 → 妙味判定は表示のみ・投票判断外
- V16 スコア取得失敗時は graceful fallback (能力列なしで通知継続)
