## Step 8: 後知恵リスク (Overfit 警告)

> **HONEST DISCLAIMER — 必ず読むこと**

1. **全パターンが後知恵発見**: 同じデータでドラッグを探しているため、実際より良く見える可能性がある。
2. **N が少ないと特に危険**: score_band (n=76), 良馬場 (n=20) は個別の高配当/低配当レースで大きく動く。
3. **SUSPECT パターンは除外フィルタに使うな**: ダート (+7.7pt) は test で -14.8pt → フィルタすると悪化するリスク。
4. **統計的有意 (p<0.05) = 因果ではない**: 条件A の p=0.007 は「hit率が高い」という観測の有意性。配当が低い理由は別。
5. **真のベリファイは paper eval のみ**: 5/23〜6/16 で各弱点条件をスキップした場合の ROI を追跡することが必須。
6. **距離/スコア欠損が大きい**: distance null 32%, top1_score null 81% → distance/score を軸にしたフィルタは実際に適用できるレース数が限られる。
