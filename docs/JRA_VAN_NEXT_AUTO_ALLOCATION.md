# JRA-VAN NEXT 自動分配機能

Session #81 (2026-05-09 夜) 調査記録。

## 背景

JRA-VAN NEXT に **予算自動分配機能** が公式提供されている。
スマホアプリでも同等機能あり。 投票自動化への 重要 piece。

## 公式機能 (確認済)

- 「それぞれの買い目に対して、 全体予算から金額を自動配分できます」
- 「全体でプラスになるような金額を自動配分することも可能」
- 「任意の馬券を選択し、 ネット投票する ボタン 1 クリックで、
   リストの買い目を PAT に送信」

要点:
- 予算 (例: 2,100 円) 入力 → 各買い目に 自動分配
- 全体 EV プラスになる 金額配分も option
- 1 click で PAT 送信 (ネット投票)

## 連携 アプリ

- **TARGET frontier JV**: NEXT 込み (PC 版、 既存)
- **スマホアプリ**: PC と同期 (買い目 リスト 共有)

## 自動分配 algorithm 推定

公式 doc に明記なし。 推定 4 案:

1. **EV ベース**: EV が高い 買い目に厚配分
2. **オッズ ベース**: 高オッズに薄配分 (リスク分散)
3. **Kelly criterion 風**: 勝率 × オッズ から 最適配分
4. **均等配分** (単純): 全買い目に 同額

→ 5/15 trial 中に 実機 で 配分結果を 観察、 algorithm 推定。

## V15 案B改 strict との 親和性

案B改 strict: 1 R あたり max 2,100 円 / フォーメーション 7 点 (条件 D: 馬連 2 点)。

NEXT 自動分配の 想定動作:
- 予算 2,100 円 入力
- 7 点 (or 2 点) 自動分配
- 1 click PAT 送信

→ **案B改 strict と 完全互換**。 V15 投資保護に 影響なし。
