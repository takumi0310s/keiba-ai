## 7. 主要発見

### 7-1. 精度シグナル (positive)
- **top3_contain_winner = 48.33%**: 予測 top3 内に 1 着馬が約半数。 random (3/N) の約 7 倍水準 (N=14 で 21%)
- **trio lift = 9.69x**: 全条件平均でランダムの約 10 倍、 条件 C/D では 13-17x と特に高い
- **top1 win rate = 23.69%**: 1 着馬を 1 位に予測する確率。 N=14 で random=7.1%、 lift ~3.3x

### 7-2. ROI ドリフト (negative signals)
- **3 月 trio hit 21.37% / ROI 76.52%**: 序盤の低調が cumulative を押し下げ
- **条件 B/E/X**: 3 条件合計 n=46 と少ないが ROI が極端に低い (8-27%)。 配当分散が大きく sample 少

### 7-3. 土曜 vs 日曜
- 日曜が土曜を ROI 面で上回る (105.35% vs 86.71%)
- 精度 (top1/top3) はほぼ同等 → 日曜高配当レース効果
- trio hit rate: 土曜 22.80% vs 日曜 23.37% (有意差なし、CI 重複)

### 7-4. 5 月 日曜の急落
- 5/11〜5/17 (日曜 n=101): trio 20.79% / ROI 64.33% / PnL ¥-25,220
- 5 月 土曜 (n=100): trio 26.26% / ROI 103.09% と好調
- 個別日程の偏りが原因と推定 (5/17 日曜単日 PnL ¥-12,160)

## 9. 計算仕様

```
Data path  : data/cumulative_results.csv
Dedup      : drop_duplicates(subset=['race_id'], keep='first')
Filter     : status == 'settled' & condition not contains 'NAR'
Date parse : str.split('.')[0] -> format '%Y%m%d'
top1 win   : top1_finish (numeric) == 1
top3 win   : any(top1_finish==1, top2_finish==1, top3_finish==1)
trio hit   : trio_hit column (0/1), bet_type=='trio' rows
umaren hit : umaren_hit column (0/1), bet_type=='umaren' rows
ROI        : actual_payout.sum() / investment.sum() * 100
Random     : 7 / comb(N, 3) * 100 (条件別 N: A/B=11, C/X=16, D=15, E=6)
CI         : bootstrap 2000 iter, seed=42, percentile [2.5, 97.5]
```
