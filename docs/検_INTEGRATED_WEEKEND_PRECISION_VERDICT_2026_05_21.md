## 各弱点の詳細分析

### Weakness #1: 距離 1601-1800m — CONFIRMED

- **主因**: 条件 A (芝1600m, n=74, ROI 41.8%) と ダート1600m (n=107, ROI 67.9%) が主体
- **メカニズム**: マイル〜中距離は本命馬が順当に来やすく三連複配当が低い。7点買いコスト (¥700) を回収困難
- **hold-out**: train +12.0pt (n=101) → test +16.9pt (n=82) → テスト期間で悪化傾向が強まる = overfit リスク低
- **改善試算**: 183R 除外 → 残 446R、ROI 109.8%
- **ただし**: p値 n.s. = hit率の差は有意でない。「配当の低さ」が主因であり hit率問題ではない

### Weakness #2: 距離 1201-1400m — CONFIRMED

- **主因**: スプリント条件D が中心。hit率 0.190 も低く、かつ配当も抑えられる二重苦
- **メカニズム**: ダート短距離は荒れにくい + 頭数が少ない傾向 → フォーメーション対象馬が絞られる
- **hold-out**: train +7.7pt (n=80) → test +15.4pt (n=67) → CONFIRMED
- **改善試算**: 147R 除外 → 残 482R、ROI 106.2%

### Weakness #3: 芝レース全般 — CONFIRMED

- **hold-out**: train +6.3pt (n=112) → test +13.3pt (n=95) → CONFIRMED
- **内訳**: 芝マイル (ROI 50.9%, n=76) が最悪。長距離芝は ROI 114.2% (n=26) と好調
- **注意**: ダートは SUSPECT (train drag だが test では -14.8pt) → ダートフィルタは PROHIBITED
- **改善試算**: 207R 除外 → 残 422R、ROI 104.9%

### Weakness #4: 未勝利クラス — 最大損失源

- **PnL**: ¥-55,650 (全クラス最大損失)
- **メカニズム**: hit率 26.3% (全体より高め) だが平均配当が薄い。人気馬が絡む低配当決着が多い
- **サブ分類**:
  - 未勝利×マイル (n=72): hit 31.9% / ROI 66.1% / p=0.046 ★hit有意高め、配当壊滅
  - 未勝利×スプリント (n=57): hit 21.1% / ROI 61.7%
- **skip改善**: 未勝利全除外 → ROI +7.5pt (推定)。ただし N 213 と大きいため絶対損失は大
- **重要**: 現行 戦略⑦ は クラス による フィルタ なし。paper eval 必須

### Weakness #5: 条件 A — 統計的に唯一有意

- **構造**: hit率 0.289 (全体 0.219 より有意に高い、p=0.007\*\*)。しかし ROI 87%
- **配当乖離**: 条件A的中時平均 ¥2,110 vs 非A的中 ¥3,680 (検-3 算出)
- **メカニズム**: 良馬場 × 中距離 × 標準頭数 = 人気収束レース。三連複が当たっても払い戻し低い
- **hold-out**: train improve +1.2pt (n=123) → test improve +8.8pt (n=71) — 後知恵リスクあり
- **推奨**: 条件A全除外は過激。まず 条件A×1600-1800m (ROI 41.8%, n=74) の paper skip を推奨

## ★ Honest 警告: Overfit リスク ★

1. **全パターン後知恵発見**: 同じデータからドラッグを探した = 実際の改善より楽観的に見える
2. **hold-out CONFIRMED = 信頼度高め (ただし n_test 小)**: 距離 #1/#2 と芝 #3 は test データでも改善を確認。この 3 パターンは最も信頼できる
3. **統計的有意なのは 条件A のみ (p=0.007)**: 距離/芝の drag は hit率でなく「配当の低さ」が主因。統計的有意でないが経済的に実在する drag
4. **SUSPECT パターンは採用禁止**: ダート (+7.7pt 全体) は test で -14.8pt → フィルタすると悪化。東京 (+5.6pt) は train データなしの結果
5. **真のベリファイは paper eval のみ**: 5/23〜6/16 の 4 週間で上記フィルタをかけた paper 成績を集計
6. **距離・surface 欠損が大きい**: distance null 32%, surface null 32% → フィルタを適用できないレースが多い (現在の morning prediction では未記録の場合あり)
