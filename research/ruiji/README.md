# SCI（類似馬場）分析ツール データ取得メモ

配布競馬分析ツール **SCI ー走破コンフォート指数ー** のデータ取得結果と JSON スキーマ。
`research/ruiji/` 内で完結。V15 運用系・`data/` には一切触れない。取得生データ（`raw/`）はコミットしない。

---

## 1. サイト構成・認証

- URL: `https://sci-ruiji-me-tt7e8scz.pages.dev/`（Cloudflare Pages）
- 認証: **合言葉フォーム POST 型**（Basic でも Cloudflare Access でもない）
  - 未認証 `GET /` → **401** + 合言葉入力 HTML
  - `POST /` に `aikotoba=<合言葉>`（form-urlencoded）→ **303** + `Set-Cookie: sci_gate=...`
  - Cookie `sci_gate`：HttpOnly / Secure / SameSite=Lax、**Max-Age=691200（8日）**
  - 合言葉は**毎週火曜更新**（note 会員記事で告知）。切れたら再 POST。
- clean URL：`analysis.html` は 308 で `/analysis` へ。存在しないパスは **SPA フォールバック HTML（`Content-Type: text/html`）を 200 で返す** → 実在判定は `Content-Type: application/json` で行うこと。

## 2. データエンドポイント

| 用途 | パス | 形式 |
|------|------|------|
| 日付ごとの出走表索引 | `/<date>/meta.json` | JSON |
| 各レースの分析本体 | `/an/<date>/<f を .html 除去し URL エンコード>.json` | JSON |
| 重賞ペース補助 | `/rj_pace.json`, `/juusho/rj_pace.json` | JSON |
| 次走ローテ補助 | `/rj_nextrun.json`, `/(juusho/)rj_nextrun/<day>.json` | JSON |

- トップ `DAYS` 配列は**今週末の重賞ハイライトのみ**（全レースは持たない）。
- 全レースは `meta.json` の `races[]` の `f` から辿る。

20260704 20260705 20260711 20260712 20260718 20260719 20260725 20260726

## 4. 取得方法（`fetch_ruiji.py`）

```
python research/ruiji/fetch_ruiji.py
```

- 認証 → 各日付 `meta.json` → 各レース JSON を順次取得。
- **全 HTTP リクエスト間 2.1 秒スリープ**（≥2s 厳守）。
- 保存先 `research/ruiji/raw/<date>/`（`meta.json` と各 `scatter_*.json`）。**再開可能**（既存ファイルはスキップ）。
- `f` が空のレース（障害戦など）は本体なしでスキップ。

## 5. レース JSON スキーマ（`raw/<date>/scatter_*.json`）

トップレベル 3 キー：`race` / `horses` / `rsim`。**当該レースの着順結果は含まれない（事前分析データ）。**
結果突合は本プロジェクト既存データ（netkeiba/JRDB）で行う方針。

### 5.1 `race`（レース属性）

| キー | 型 | 意味 |
|------|----|------|
| `no` | int | レース番号 |
| `v` | str | 競馬場（札幌/新潟/中京…） |
| `n` / `nfull` | str | レース名 / 正式名 |
| `g` / `gc` | str | グレード表示（GIII 等） / グレードコード（g3） |
| `t` | str | 発走時刻 |
| `s` | str | 芝 / ダ |
| `dist` | int | 距離(m) |
| `h` | int | 頭数 |
| `st` | str | 馬場状態（良/稍/重/不） |
| `tx` | float | ★当該レースのクッション値（類似度計算の tcv。トップ `dome.cv` 相当）★ |
| `ty` | float | ★当該レースの含水率（類似度計算の tm/ty。芝=`dome.tm`, ダ=`dome.dm` 相当）★ |
| `date` | str | 開催日 yyyymmdd |
| `f` / `nf` / `pf` | str | 自ファイル名 / 次レース / 前レースファイル名 |
| `ky` | str | 脚質傾向テキスト（"逃げ61%・先行46%"） |
| `pace` | str | 想定ペース（S/M/H） |
| `kyc` | list | 脚質構成 `[["逃げ",61],["先行",46],...]`（%） |
| `kyt` | list | 有利脚質 `["逃げ","先行"]` |
| `mey` | dict | 位置取り目安 `{c1, c4, ag, ar}`（下記 rsim.meyasu と同） |

### 5.2 `horses[]`（出走各馬）

| キー | 型 | 意味 |
|------|----|------|
| `num` | str | 馬番 |
| `waku` | int | 枠番 |
| `name` | str | 馬名 |
| `sa` | str | （斤量/性齢系。事前snapshotでは空のことあり） |
| `jk` | str | 騎手（事前snapshotでは空のことあり） |
| `wt` | str | 馬体重（事前snapshotでは空のことあり） |
| `ky` | str | 予想脚質（逃げ/先行/好位/中団/後方） |
| `runs` | list | 直近過去走（最大5件、各15要素配列。下記） |

### 5.3 `horses[].runs[]`（過去走・15要素配列）★JSソース定数で全確定★

添字の意味は `analysis.html:809` の定数 `const R_DR=0,...,R_MO=14` で**確定**（推定ではない）。

例: `["20260620","阪神","3歳未勝利(牝)",1800,"ダ",9,16,1.5,"マクノス","13-13-9-9",38.1,40.8,10,9.7,5.0]`

| idx | JS定数 | 意味 |
|-----|--------|------|
| 0 | R_DR | 走破日 yyyymmdd |
| 1 | R_VEN | 競馬場 |
| 2 | R_RN | レース名（クラス判定に使用） |
| 3 | R_DIST | 距離(m) |
| 4 | R_SURF | 芝/ダ |
| 5 | R_RES | 着順 |
| 6 | R_NH | 頭数 |
| 7 | R_TD | 着差（勝ち馬との差、秒。1着は0） |
| 8 | R_WIN | 勝ち馬名（自身1着なら2着馬） |
| 9 | R_PASS | 通過順位（"13-13-9-9"、脚質判定に使用） |
| 10 | R_MAE | **前半3F（テン、秒）** |
| 11 | R_AG3 | **上がり3F（自身、秒）** |
| 12 | R_AGR | **上がり3F順位（★人気ではない★）** |
| 13 | R_CV | **★クッション値（その過去走の芝馬場コンディション）★** |
| 14 | R_MO | **★含水率%（その過去走の馬場コンディション）★** |

> ★**idx13/14 の正体＝馬場コンディション座標（Phase A 確定、§8参照）**★
> - `R_CV=クッション値`・`R_MO=含水率`。散布図はこの2値を X/Y 軸にプロットし、当該レース馬場 `race.tx`(クッション)/`race.ty`(含水) との距離＝**類似度**を計算する（`calcSim`）。
> - つまり idx13/14 は「予測指数」でも「オッズ」でもなく、**その過去走を行った日の馬場条件**。60,214 走の分位検証でも着順とほぼ無相関（§8.3）。
> - 当初の「idx14=単勝オッズ」「idx12=人気」仮説はいずれも棄却。runs にオッズ・人気は含まれない。

### 5.4 `rsim`（レースシミュレーション/集計）

| キー | 型 | 意味 |
|------|----|------|
| `ag3` | dict | 馬番→想定上がり3F `{"1":38.0, "2":37.75, ...}` |
| `kyaku` | dict | 脚質別・複勝関与率 `{"逃げ":61,"先行":46,"好位":19,"中団":5,"後方":1}` |
| `meyasu` | dict | 位置取り目安 `{c1, c4, ag, agr}`（c1=1角位置, c4=4角位置, ag=上がり, agr=上がり関連） |
| `meyasu2` | dict | 同・別条件版の目安 |

## 8. Phase A — idx13/14 の意味特定（★確定★）

JS ソース（`analysis.html`）の解析で完全解決。

### 8.1 結論
- **idx13 = R_CV = クッション値**、**idx14 = R_MO = 含水率**（いずれもその過去走の**馬場コンディション**）。
- ツールの正体＝**類似馬場マッチング**エンジン。各過去走を「クッション値×含水率」平面にプロットし、当該レースの馬場（`race.tx`/`race.ty`）に近い過去走ほど高類似度。
- 「走破コンフォート指数(SCI)」の名の通り、**指数 = 馬場条件の近さ + そこでの走り**であり、idx13/14 自体は予測スコアではない。

### 8.2 類似度の算出式（JS `calcSim`）
```
芝: 類似% = max(0, 100·(1 − (|Δクッション| + |Δ含水|·0.5) / 6.0))
ダ: 類似% = max(0, 100·(1 − |Δ含水| / 15.0))          # ダートはクッション値なし=含水のみ
    Δクッション = |past.R_CV − race.tx| ,  Δ含水 = |past.R_MO − race.ty|
```
`buildSim`：各馬の直近10走を race単位でまとめ、当該日より前のみ、類似度 pct を付与。

### 8.3 idx13/14 非予測性の実証（60,214 全過去走の5分位）
| | q0 | q1 | q2 | q3 | q4 |
|--|--|--|--|--|--|
| idx13 クッション値・複勝率 | 32.1% | 29.5% | 29.0% | 26.2% | 27.2% |
| idx14 含水率・複勝率 | 29.1% | 29.4% | 28.6% | 28.5% | 28.4% |

→ 含水はほぼフラット、クッションも ~5pt 程度（距離/クラス交絡の域）。**idx13/14 は結果を予測しない＝馬場タグである**ことを確認。

## 9. Phase B — 7機能・フィルタ全定義（JSソース準拠）

`tool_filters.py` に忠実移植（`calcSim`/`buildSim`/`styleOfRun`/`rowPassF`/`passF`/`firstStart`）。実 JSON で動作検証済。

### 9.1 過去走の脚質判定（`styleOfRun`）
最終コーナー位置 c1（通過順の最後の非0値）と頭数 n から：
`c1==1→逃げ / c1/n≤0.30→先行 / ≤0.50→好位 / ≤0.75→中団 / それ以外→後方`

### 9.2 フィルタ `F` の全定義（ピル/ドロップダウン）
| ピル | フィールド | 判定（行=過去走 q, 馬=x） |
|------|-----------|--------------------------|
| 好走 | `F.good` | 行: `q.res≤3 または q.td≤0.6` |
| 同脚質 | `F.ky` | 行: `styleOfRun(q) ∈ race.kyt`（有利脚質） |
| 上がりN位内 | `F.agari`(1–18) | 行: `q.agr ≤ N`（agr=上がり順位) |
| グレード | `F.grades` | 馬: `clsOf(x.rn) ∈ 選択グレード` |
| 類似度N%↑ | `F.sim`(10–90) | 馬: `x.pct ≥ N` |
| N着内 | `F.rank`(1–18) | 行: `q.res ≤ N` |
| 1着差+N.N秒 | `F.td`(0.1–3.0) | 行: `q.res==1 または q.td ≤ N` |
| 1着差+0.0 | `F.td0` | 行: `q.res≠1 かつ q.td<0.05`（惜敗） |
| その他 | `F.oth` | 下記7種 |

`F.oth`（`OTH_DEF`）: `first`(1着のみ=行 q.res==1) / `scls`(同クラス) / `sdist`(同距離=同芝ダ&同m) / `sven`(同競馬場) / `y1`(1年以内) / `turf`(芝のみ) / `dirt`(ダのみ)。

判定の要点（JS 2026-08-02 修正準拠）: **1頭が全条件を満たす「行」を持つか**の AND 判定（条件ごとの some() ではない）。

### 9.3 7分析機能 ↔ データ対応
散布(クッション×含水プロット+類似度) / シミュ(rsim.ag3/kyaku/meyasu) / 隊列(rsim.meyasu+通過順) / ハナ(kyc逃げ%) / 馬場(race.st/tx/ty+dome) / フィット(buildSim+フィルタ) / ☆(好走ハイライト)。
※ rsim は**着順確率ではなく**、脚質別複勝関与率(`kyaku`)と想定上がり(`ag3`)・位置取り(`meyasu`)。

## 10. Phase C — 結果突合 & 予測力一次検証（`merge_results.py`）

### 10.1 突合方針（★外部データ不要・ツール内自己完結★）
- `data/` の JRA per-horse 結果は **2026-05-03 で停止**（jra_races_full/JRDB bac・sed とも）。ツール窓 6/6–8/9 は未カバー。予測台帳 `cumulative_results.csv` は 20日中7日のみ・全馬着順なし。
- 代替：**ツール自身の過去走記録を20ファイル跨ぎで集約**。ある日の走は次走時の後続ファイルに着順込みで残るため、対象馬の実着順を復元。
- 復元カバレッジ **3,416/8,972 = 38.1%**（6/6・6/7＝100%、後半は将来ファイル不足で低下: 8/8・8/9＝0%）。
- **限界**: ①オッズ/配当はツールに無い→**回収率は算出不可**、複勝率(top3)のみ。②「次走あり馬」への選択バイアス。③後半日付ほど低カバレッジ。

### 10.2 一次回答：idx13/14 に予測力はあるか → **生の idx13/14 は No。ツール派生シグナルは Yes**
復元サブセット n=3,416（ベース複勝率25.6%）の分位×複勝率：

| シグナル | 最下位分位 | 最上位分位 | 傾向 |
|----------|-----------|-----------|------|
| **rsim予測上がり順位**(小=速) | 43.6%(速い側) | 7.4%(遅い側) | 強い単調(+36pt) ★最強★ |
| **類似馬場での好走率** `simgood_rate` | 13.9% | 37.2% | 強い単調(+23pt) ★有効★ |
| 最大類似度 `sim_pct_max` | ~22–30% | ~22–30% | ほぼフラット（馬場一致だけでは当たらない＝妥当） |
| idx13/14 生値（§8.3） | — | — | 無相関 |

→ **ツールの信号は「rsim予測上がり」と「類似馬場での好走実績」に宿る**。idx13/14 は入力（馬場座標）であって出力指数ではない。ただし**回収率での市場超えは未検証**（オッズ欠落）＝この段階では「複勝率と相関」までが確定。
