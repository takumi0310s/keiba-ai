# v16-fundamental（v16f）— 設計調査 & 先行実験

V15 pkl・運用系は不変。`research/v16f/` で完結。data/ は読み取りのみ（書き込み禁止）。

## 仮説
V15 は「能力 + 市場（オッズ/人気代理）」を混ぜて学習しており ROI は市場並み（複回~75%）。
**純能力のみ**で学習した模型なら、市場が見落とす馬（モデル高評価×市場薄）を拾えるのでは、という仮説。

## 2. 先行実験（コスト最小・既存 Pattern A で乖離注入バックテスト）

`prelim_divergence.py`。新学習の前に、既存 Pattern A の乖離馬を V15 三連複フォーメーションに
注入した場合の ROI 変化を測定。

### データ経路（再計算なし）
- 特徴量: `data/v15_feat_dump/<date>/<race_id>.parquet`（145特徴が0欠損で格納）。
- 結果/オッズ/配当: `research/ruiji/raw_results/`（SCI検証で取得済）。
- 予測: Pattern A pkl（LGB+XGB, weights）で per-horse 予測。

### ★重大な実現可能性の制約★
- **640R窓のうち Pattern A が健全なのは JRDB生存の6日（6/6,6/7,6/13,6/14,6/20,6/21）＝186R のみ**。
- **6/27以降は JRDB全滅（40/40特徴が定数）→ Pattern A 予測が崩壊**（corr(本番)0.01-0.17・範囲圧縮）。
  同時に **V15本番スコア自体も劣化**（8/2の本番スコア範囲0.14-0.32 vs 健全日0.0-0.9）＝運用課題（別件）。
- leak-free 学習キャッシュは **2020-2025 のみ・2026は0行**（640Rの学習分布外）。

### 結果（186R・JRDB健全6日）
| フォーメーション | 的中率 | ROI |
|-----------------|--------|-----|
| 現行 V15（7点） | 28.5% | 63.9% |
| 入替（n6→乖離馬） | 28.5% | **63.9%（現行と完全一致）** |
| 追加（8点化） | 28.5% | 61.3%（投資増で悪化） |

乖離馬ありレースのみ（28R）でも 入替=現行と同一・追加は悪化。

### 結論: 先行実験は「効果なし」かつ「既存Pattern Aでは検証不能」
- **乖離注入の効果はゼロ**（入替が現行と1円も変わらない＝乖離馬は勝ち三連複を1本も完成させず）。
- 根本原因: **既存 Pattern A は V15本番と corr 0.98-0.99・市場をほぼなぞる**（オッズ系a+市場代理bを含むため）。
  → 乖離馬が出るのは 186R中 **28R のみ**、しかも無効。**既存Pattern Aは仮説の検証に不向き**。

## 3. 判断（次段階の推奨）

先行実験は**仮説を棄却も支持もしない（＝既存Pattern Aが市場結合しすぎて乖離が出ない）**。
真に検証するには **c（純能力125）のみで再学習した模型**が必要。ただし:

- **640R/2026 での評価は JRDB全滅により不可能**（6/27以降・特徴量崩壊）。健全なのは6月の186Rのみ。
- 従って c-only 模型の評価は **leak-free キャッシュ 2020-2025 の WF-OOF 乖離分析**（大n・リークフリー監査済）で行うのが妥当。
  - 手順案: c125特徴で LGB+XGB を V15同一WF fold（2021-25）学習 → OOF予測 → キャッシュの `oz_*`（市場）と乖離 → 乖離上位馬の複勝率/単複回収を市場ベースライン比較。
- これは item2+3 をキャッシュ上で実施する形（640R形成バックテストは 2026特徴の健全性回復まで保留）。

★ 次アクション候補: c-only 再学習（キャッシュ2020-25、~数分）→ 乖離の市場超過を大nで判定。
本先行実験の「効果なし」は既存Aの市場結合が原因で、c-only では結果が変わりうる（未検証）。

## 4. A. c-only 再学習 + 事前登録評価（`train_c_only.py`）★GO（但し要確定オッズ検証）★

c125特徴のみで LGB+XGB を WF(2021-25)学習→OOF(235,840行/17,277R)。事前登録(PRE_REGISTRATION.md)通り判定。

### WF-OOF AUC（参考）
fold別 0.825/0.829/0.828/0.834/0.831（平均 ~0.830）。※市場特徴を抜いたため V15(0.868)より低い＝設計通り。

### 事前登録の判定
- 市場ベースライン(全馬 base複勝回収)= **59.5%**
- ★最上位 divergence デシル（モデル≫市場, n=23,584, 中央単勝odds 12）★
  - **複勝率 46.9%**・**複勝回収 131.1%・95%CI[129.0, 133.2]**・単勝回収155.2%(参考)
- 事前基準: CI下限 129.0% > 市場ベースライン 59.5% → ★**GO**★

### デシル単調性（参考・判定外）
divergence 0→9 で複勝率 33.8%(favorites)→[中位10%]→**46.9%**。乖離最大群が最高複勝率＝
「モデルが市場より高評価」が的中している U 字。

### ★重大な解釈上の限界（結論を過信しない）★
- ★**リークフリーキャッシュは確定オッズを masking（tansho_odds/odds_log が全定数）→ 使えるのは base(朝)オッズのみ**★。131%は**朝ラインに対する優位**であり、確定市場超えの証拠ではない。
- base オッズは payout を一様過小評価（全馬 base複勝52% vs 実~78%）→ 確定なら top-decile はより高い可能性。一方 top-decile は朝の人気薄＝終値で買われ下げられた可能性もあり、両効果は逆向き・**確定オッズ無しでは純益は判定不能**。
- ★ただし **複勝率46.9%（同人気帯~22%比 +20pt超）はオッズ非依存の実シグナル**★＝c-onlyは朝ラインが見落とす地力を捉えている。先行実験(既存A=null)と対照的に**方向性はポジティブ**。
- AUC 0.83（非水増し）＝グロスなリークの兆候なし。

### 判定と次
- 事前登録上は **GO**。ただし「朝ライン超え」であり **確定市場超えは未検証**。
- ★決定的検証＝**確定オッズでの複勝回収**★ → (a) JRDBバックフィル後の 2026/640R（確定オッズは research/ruiji/raw_results に既存）で c-only を評価、(b) or 確定オッズ付きキャッシュの再構築。
- v16f は「棚上げ」ではなく「**確定オッズ検証へ進む価値あり**」（先行実験の null を、市場特徴を抜いたことで覆した）。
