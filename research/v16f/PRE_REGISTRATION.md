## モデル
- 特徴量: **c（純能力）125特徴のみ**（a.直接オッズ7 + b.市場代理13 を除外。README §1 の分類）。
- データ: `data/_v15_optuna_df_cache_leakfree_v2.pkl.gz`（leak-free v2, 527,280行, 2018-2025）。
- WF fold: Y ∈ {2021,2022,2023,2024,2025} について **train=year<Y / predict=year==Y**。OOF=各Yの held-out 予測を結合。
- 学習器: LGB + XGB（V15 と同一ハイパーパラメータ, CLAUDE.md 記載値）。アンサンブル=単純平均。
- 目的変数: `target`（finish ≤ 3, 複勝圏）。

## 乖離（divergence）の定義
- レース内で正規化: model_prob_norm = 予測 / レース内合計。market_prob_norm = (1/単勝base odds) / レース内合計（単勝odds=exp(oz_tansho_base_log)）。
- **divergence = model_prob_norm − market_prob_norm**（正=モデルが市場より高評価）。
- 全 OOF 馬行を divergence で 10 分位に分割。

## 検定セル（事前宣言・1つのみ）
- **最上位デシル（divergence 最大 = モデルが市場を最も上回る群）**。他デシルは参考記録のみ・判定に使わない。

## 指標と GO/NO-GO 基準
- 複勝回収 ROI = mean( 複勝return ) / 1.0、複勝return = exp(oz_fukusho_base_log) if finish≤3 else 0（base複勝オッズを払戻proxy）。
- **レースクラスタ bootstrap 95%CI**（n=2000, レース単位リサンプリング）。
- 市場ベースライン = 全 OOF 馬行の複勝回収 ROI（パリミュチュエル控除後水準）。
- ★**GO 条件: 最上位デシルの複勝回収 ROI の 95%CI 下限 > 市場ベースライン ROI**★
  - 満たせば「純能力モデルは市場が見落とす複勝価値を拾える」= v16f 前進。
  - 満たさなければ **NO-GO**（デシルを細かく切り直して良いセルを探す後付けは禁止）。
