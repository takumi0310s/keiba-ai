## 6. TYB 公開タイミングの真実

```
midday_v17_ultra_5_3.sh 14:50 実行 → TYB260503 HTTP=404
```

JRDB の Tyb (直前データ) は本来 **発走前数時間に公開** (5分前ではない)。  
ただし 5/3 14:50 時点で 5/3 京都11R (15:40 発走) の TYB 未公開。

**仮説**: JRDB Tyb 公開は **当日朝以降、発走 1-2時間前** の可能性高い。  
→ midday 戦略 (発走15分前) は不適切、**発走 30-60分前にリトライ** する設計に変更必要。

ただし 5/3 ログでは 14:50 (発走 50分前) で 404 → publish は当日朝でなく **post-race** (17:00 以降) の可能性も。

→ **TYB の直前予測戦略は Phase 2.5 で publish タイミング再調査必要**。
