## 3. 三連複 7 点 (v2 推奨買い目)

軸: **#8 ミッキーファイト**
2列目: **#10, #2** (旧 #2, #10 から swap)
3列目: **#10, #2, #1, #13, #3** (5 通り)

```
組合せ 7 点:
  1. 8-10-2  (旧 8-2-10、表示順だけ swap)
  2. 8-10-1
  3. 8-10-13
  4. 8-10-3
  5. 8-2-1
  6. 8-2-13
  7. 8-2-3
```

→ v1 と組合せ集合は同一 (順序のみ swap)。**7 点の本質は変わらない**。

### 3.1 v1 と本質的に変わる点

- **#1, #13 の 3 列目 配置を 注目**: v1 は 1, 13 が 4-5位、v2 も同様
- v1 で `8-10-13` `8-10-1` などは含まれていた → **v2 で買い目同一**

→ **形式 上の三連複 7 点は v1 = v2** (NAR v4 と本質一致)。
→ 差分は **「軸馬の信頼度」と「相手 #10/#2 のどちらを重視するか」** だけ。

### 3.2 形式拡張案 (v2 でのみ実施可能):

#10 を 2列目 先頭に変更すると、フォーメーション買い目で 重視度が変わる:
- 案 A': `8-10-{2,1,13,3}` 4 点 (#10 軸並び、各 100円 = 400円)
- 案 B': `8-{10,2}-{10,2,1,13,3}` 7 点 (上記同) = **三連複 7 点 (700円)**

→ 通常運用 (案B') で 7 点 = 700円 投資、配分は v1 と同じ。

### 4.1 信頼度評価

**v2 信頼度: 中-高**
- ハイブリッド score 1位 (#8 ミッキーファイト 4.76) は **2位 (#10 4.20) との差 +0.56** で軸として明確
- 1.5倍 堅軸 → 馬 自体の予測 信頼度 高
- ただし **配当 旨味少** (1.5倍 軸) → EV 期待値はマイナス気味
- **遊び投資としての位置付け**、実弾としては慎重

### 4.2 v1 との 投資判断 差

- 買い目: **同一** (順序入替のみ)
- 配分上限: **同一** (700 / 1,400 / 2,100 円)
- 信頼度: v2 で **微増** (3 source 統合 + 過去傾向考慮)
- → v2 推奨は **案 A' 700円** (慎重) が妥当

## 5. 期待 ROI 分析

NAR v4 model + ハイブリッド score で軸 + 相手選定 信頼度 高。

| 命中シナリオ | 三連複 払戻 (推定) | ROI |
|-------------|-------------------:|---:|
| 8-10-2 (確率 ~25%) | 1,500-2,500 円 | 200-350% |

→ EV 1.0 ぎり程度。**遊び投資、毎週 投入は推奨しない**。
