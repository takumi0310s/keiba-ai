## root cause

**Phase 4 (5/10 朝) 実装時、 RACE_START_TIMES に 5/10 race_ids 追加時:**

- 「5/9 same time slot 仮定」 で 5/9 hardcoded 時刻を copy
- JRA 開催日の発走 schedule は 日々若干変動 (3-20 min 程度)
- 5/10 真値を取得せず、 5/9 値を流用 → 平均 8 min ズレ発生

**正しい source**: 
- race_auto_notify.get_todays_races() は netkeiba race_list_sub から real-time 取得済
- 既存実装 = OK だが、 stage2_predict は static dict を使用 = bug

**修正方針**:
- 5/10 RACE_START_TIMES を 真値で上書き (即修正)
- 5/16 (来週土) 以降は dynamic 取得化 検討 (race_auto_notify.get_todays_races() 連携)
