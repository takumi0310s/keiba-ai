## 1. Kelly 基準の数式

### 1.1 標準 Kelly

```
f* = (b * p - q) / b
   = (b * p - (1 - p)) / b
```

- f*: 資産に対する optimal fraction
- p: 勝率 (V15 case: top1 が 1〜3 着 = 三連複 hit)
- q: 1 - p
- b: net 配当倍率 (= payout / 賭金 - 1)

### 1.2 Fractional Kelly (実運用版)

Full Kelly は推定誤差で破綻リスク高 → 半分 (Half Kelly) や 1/4 Kelly を使う。

```
f_actual = α × f*  (α = 0.25-0.5)
```

   = 1.570 / 4.71
   = 0.333  (= 33.3%)

## 3. なぜ Quarter Kelly より保守的に運用するか

### 3.1 推定誤差リスク

V15 BT の 三連複 hit 率 0.45 は **過去データ平均**:
- 95% 信頼区間 ROI [135.9%, 222.4%] → hit 率の信頼区間 [0.38, 0.55]
- p の不確実性が Kelly 計算精度を直撃 (Full Kelly は p = 0.45 を確定値として扱う)

→ 実際の真の p が 0.38 だった場合の Full Kelly:
```
f* = (4.71 * 0.38 - 0.62) / 4.71 = 0.241  (= 24.1%)
```
→ 0.38 想定でも Quarter Kelly (8.3%) を超える。

### 3.2 撤退ラインとの整合

| 累計収支 | 状態 | アクション |
|---------|------|----------|
| ≥ 0 | 順調 | 計画通り |
| -10,000 ≦ x < 0 | 注意 | 翌週 投資停止 |
| -50,000 ≦ x < -10,000 | 警告 | 全停止 |
| < -50,000 | **撤退** | 完全停止 |

現在 +13,530円 → 撤退ライン -50,000円 まで余裕 +63,530円。

Full Kelly (4,503円/R) を 5/9 (3R 想定) で実行: 13,510円投資 → 全外しで -13,510円。
Half Kelly (2,260円/R × 3R = 6,780円): 全外しで -6,780円。
**案B改 (700円 × 3R = 2,100円)**: 全外しで -2,100円 (撤退余裕の 3.3% のみ消費)。

→ 案B改 が 撤退余裕に対して **1/30 規模** で、 累計損失リスクを最小化。

### 3.3 連敗リスク

V15 BT で 平均 連敗 max ≈ 6 R (95% percentile)。
- Full Kelly 連敗 6 R: -4,503 × 6 = -27,018円
- Half Kelly 連敗 6 R: -2,260 × 6 = -13,560円
- **案B改 連敗 6 R**: **-700 × 6 = -4,200円** (撤退余裕の 6.6%)

→ 連敗 max でも撤退ライン -50,000円 まで余裕。

## 4. 動的 Kelly (将来検討、 5/24+ Phase 3)

### 4.1 概念

各 race の 信頼度 (winner_top1 score) に応じて投資額を調整:
```
bet_amount = base * (score / score_baseline)
score > 0.85 → 1.5x base (1,050円)
0.75-0.85   → 1.0x base (700円, 案B改 と同)
0.65-0.75   → 0.7x base (490円)
< 0.65      → 0 (見送り)
```

### 4.2 Phase 3 採用判定基準

- V18/V19 v2 (sib_*_exp 版) GO 条件: winner_top1 ≥ 30%
- → score 0.65-0.75 帯で hit 率 〜 0.30 確認できれば 0.7x
- → 0.65 未満は完全見送り (Kelly f* < 0)

### 4.3 V20 投入後 (7/1+)

V20 ROI 想定 140-145% で Kelly f* ≈ 0.20-0.25:
- Quarter Kelly ≈ 5-6.3% (= 700-880円/R 換算)
- 案B改 5.2% は Quarter Kelly に整合

→ V20 投入後も 案B改 と同じ 700円/R baseline 維持で十分保守的。
