## 1. 5/3 結果から判明した課題 (新規)

### 課題1. trio 7点 命中の律速段階は TOP2-TOP6 選定精度

5/3 USER 6R で軸top3 は 3/6 (50.0%) と健全 (BT 57.0% に近接) だが trio_hit は 1/6 のみ。

**惜敗ケース** (軸top3 だが trio 外し):
- 越後S: 軸 10 ユキマル 2着 ✓ / trio 結果 3-4-10 / 買い目に「3-4-10」**なし** (TOP2-TOP6 候補に 3,4 両方を含めなかった)
- 東京12R 4歳以上2勝: 軸 5 エイプリルインパリ 1着 ✓ / trio 結果 5-10-13 / 買い目に「5-10-13」**なし** (10 が TOP2-TOP6 圏外)

→ **対応**: TOP2-TOP6 拡張 (top6 → top8) または相手スコアの calibration 再検証。Phase 2.5 #15 として追加。

### 課題2. V15 軸top3 率 が BT 平均に届かない (5/2/5/3 共通)

| 期間 | V15 軸top3率 | BT との差 |
|------|-------------:|----------:|
| BT 4/11-4/26 平均 | 57.0% | basis |
| 5/2 全33R | 39.4% | -17.6pt |
| 5/3 全34R | 41.2% | -15.8pt |

5/2 → 5/3 で +1.8pt 微改善だが gap -16pt 程度のまま。**systematic な構造差** が継続している可能性。may2_postmortem の P=0.032 は 5/3 でも有効 (5/3 単独 P値は計算未実施だが trio_hit 11.8% < BT 22.0% で同様傾向)。

→ **対応**: Cookie 復旧 + netkeiba_race_analysis (ra_score) 再開で features 復元 → 5/9 までに gap 縮小を確認。

### 課題3. 人気1位 proxy ROI ギャップは縮小傾向

| 日付 | V15 軸top3 | 人気1位軸top3 | gap |
|------|-----------:|--------------:|----:|
| 5/2 | 39.4% | 66.7% | **-27.3pt** |
| 5/3 | 41.2% | 52.9% | -11.7pt |

5/2 → 5/3 で gap -27.3 → -11.7pt と半減。**5/2 だけ人気1位が異常高 (G1祭事の影響)** だった可能性が浮上 — 5/2 の systematic 疑いの一部は曜日/イベント特殊性で説明可能。

→ **対応**: V15 vs 人気1位の log を週次で蓄積、3週間で安定 gap を測定。Phase 2.5 #16 として追加。

### 課題4. odds_base 5/3 未生成 → EV計算未稼働

system_audit_5_3.md A1 で確認済。Phase 2 BT (v18 ROI 295%) は前日朝オッズで実施されたが、5/3 本番に同条件を適用するには odds_base/20260503.csv が必要。これがない限り **v18/v19 を 5/3 retro検証できない**。

→ **対応**: Phase 2.5 #5 (odds_base 構築) を **最優先タスクの一つ** に格上げ。

## 4. 5/9 (土) GW後 実本番テスト の投資配分提案

### 戦略の前提

5/3 USER 実投資 (4,200円) ROI 87.6% は BATCH 31.3% の **2.8倍**。**主要レース選別 + 三連複7点固定** の戦略は単純 BATCH より優位。これを基本ラインとする。

### 提案A (推奨、conservative)

V15 単独、5/3 と同等の主要 5-7R 限定。

| レース選定基準 | 投資/レース | 想定レース数 | 想定総額 |
|----------------|-------------:|-------------:|---------:|
| G1, G2, G3 | 1,000-1,500 | 1-2 | 1,500-3,000 |
| L (リステッド), OP特別, 主要重賞 | 700 | 2-4 | 1,400-2,800 |
| 平場 1勝/2勝クラス、軸スコア > 0.85 のみ | 400-700 | 1-2 | 400-1,400 |
| **合計** | | **5-8R** | **3,300-7,200** |

**シミュレーション** (5/2-5/3 平均 USER ROI 50% 想定):
- 投資 5,000円 × 0.50 = 期待払戻 2,500円 → 期待収支 -2,500円
- BT 平均 (USER 主要絞り) ROI 130% 仮定: +1,500円

期待値はマイナス〜微プラス。 **リスク管理優先で 5,000-6,000 円規模に抑える。**

### 提案B (積極、retro検証 OK 時のみ)

V15 主要 5-7R + V18 単勝 軸 (V15と異馬の場合のみ並列ベット)。

| 戦略 | 投資/レース | 想定レース数 | 投資 |
|------|-------------:|-------------:|-----:|
| V15 三連複7点 (主要絞り) | 700 | 5-6 | 3,500-4,200 |
| V18 単勝 (V15 と相手異馬時) | 200 | 0-3 | 0-600 |
| V19 複勝 (確率 > 0.70) | 200 | 0-2 | 0-400 |
| **合計** | | | **3,500-5,200** |

**条件**: 5/4-5/8 で v18 retro検証で 5/2-5/3 ROI > 200% を確認できた場合のみ提案B 適用。

### 提案C (撤退、緊急時)

5/4 retro検証で v18 ROI < 130% かつ V15 改善見込み無しの場合: **5/9 は実弾投入を中止**、観戦のみ。
