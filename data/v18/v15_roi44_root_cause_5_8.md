## 1. CRITICAL DISCOVERY: ROI 44.47% は集計 bug 起因の過小評価

### 1.1 Session #42 C の集計方法

`tools/extended_retro_4_12_5_5.py` で `actual_payout` 列を集計:

```python
total_pay = float(settled['actual_payout'].sum())
roi = total_pay / total_inv * 100
```

### 1.2 bug 原因

`data/daily_results/<date>.csv` の format 進化:
- 旧 format (4/18-4/19 等): `actual_payout` 列 **なし**、 `trio_payout` のみ
- 新 format (5/3 以降): `actual_payout` 列追加

旧 format の行で `actual_payout` が NaN → `fillna(0)` で 0 扱い → **payout が大幅過小評価**

### 1.3 修正版 (本 Session A): profit + investment = payout

```python
settled['payout_calc'] = settled['investment'] + settled['profit']
total_pay = settled['payout_calc'].sum()
```

→ profit 列は **全 date で 信頼性あり** (source of truth)
